# Política de cambios de pedido

**Versión:** 2026-08 · **Vigente desde:** 1 de agosto de 2026

## Cambios antes del envío

Mientras un pedido esté `Processing`, soporte puede solicitar la corrección de
dirección, el ajuste de un dato de contacto o la cancelación. Todo cambio debe
confirmar primero la identidad del cliente y la referencia del pedido. El
curso usa esta regla para diferenciar datos actuales, que llegan de una
herramienta, de las reglas documentales que explican qué se permite.

No se permite cambiar un producto ya confirmado dentro del mismo pedido. El
cliente puede cancelar el pedido si aún está en preparación y crear una compra
nueva. Esta separación evita alterar el precio, el stock o la garantía de una
línea que ya ha sido asignada por el almacén.

## Cambios después del envío

Cuando el estado es `Shipped`, la dirección no se modifica desde soporte. Se
puede indicar que el cliente contacte con el transportista usando el tracking,
pero no se debe prometer que el cambio se aplicará. Para pedidos `Delivered`,
los cambios se sustituyen por el flujo de devolución o garantía.

Las peticiones que impliquen modificar datos persistentes requieren aprobación
humana en el curso. Las herramientas del agente base son de solo lectura y una
política deniega intencionadamente cualquier operación de escritura.
